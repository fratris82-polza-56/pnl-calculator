план/факт · прогноз выполнения

План и факт по месяцам (выручка, млн ₽)

Накопленный план/факт по дням (сентябрь)

Сводная таблица

прогноз = факт/день × дней в месяце; % — к плану

Сотрудники

личный план = план аптеки × доля; доли правится в API (PATCH /api/employee/:id)

Обмен данными с аптечным ПО REST API

Аптечная программа (1С/МИС) отправляет ежедневные продажи пакетом — дашборд сам раскладывает факт по аптекам, сотрудникам и дням. Совпадение сотрудника — по ФИО (без учёта регистра). Нераспознанные ФИО копятся в логе разметки.

POST /api/integration/sales — пакет продаж:

# пример: продажи аптеки №1 за 29 сентября
curl -X POST http://<host>:8080/api/integration/sales \
  -H "Content-Type: application/json" \
  -d '{"pharmacy_id":1,
       "sales":[{"doc_id":"Ч-1042","d":"2026-09-29",
                 "employee_name":"Иванова А.С.",
                 "amount":1250.50,"margin":310.20}]}'

GET /api/summary?pharmacy_id=&month= — план/факт/прогноз

GET /api/s.series?pharmacy_id=&month= — факт по дням

GET /api/catalog — аптеки, план, сотрудники

POST /api/fact — ручная правка дня

PATCH /api/employee/:id — ФИО/доля сотрудника
