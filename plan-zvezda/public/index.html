Обмен данными с аптечным ПО REST API

Аптечная программа (1С/МИС) отправляет ежедневные продажи пакетом по HTTP — без ручной загрузки файлов. Дашборд сам раскладывает факт по аптекам, сотрудникам и дням. Повторная отправка того же пакета не создаёт дублей (по номеру чека). Совпадение сотрудника — по фамилии+инициалам; нераспознанные ФИО копятся ниже и доначисляются кнопкой «Повторить разметку».

Ключ доступа: … · 📄 Спецификация для вендора ·

POST /api/integration/sales — пакет продаж (заголовок X-Intg-Key, полная спецификация: /integration):

# пример: продажи аптеки №1 за 29 сентября
curl -X POST http://<host>:8080/api/integration/sales \
  -H "Content-Type: application/json" \
  -d '{"pharmacy_id":1,
       "sales":[{"doc_id":"Ч-1042","d":"2026-09-29",
                 "employee_name":"Иванова А.С.",
                 "amount":1250.50,"margin":310.20}]}'

GET /api/summary?pharmacy_id=&month= — план/факт/прогноз

GET /api/s.series?pharmacy_id=&month= — факт по дням

GET /api/catalog — аптеки, план, сотрудники

POST /api/fact — ручная правка дня

PATCH /api/employee/:id — ФИО/доля сотрудника

POST /api/stockout · GET /api/stockout/top?days=7 — отказы и топ

POST /api/coupon — возвраты купонов · GET /api/kpi — KPI квартала
