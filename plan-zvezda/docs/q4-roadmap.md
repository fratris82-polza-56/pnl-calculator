## 3. Вехи квартала

1. **15.10** — двойные ворота: go/no-go листовок + вердикт по Маяковской. Самая важная дата квартала: от неё зависят ноябрь и декабрь.
2. **1.11** — решение о платном трафике (только при доказанном CAC ≤100₽).
3. **27.11** — Чёрная пятница: до 5–7% квартального ТО за один день.
4. **10.11 / ежедневно с 14.12** — ноль отказов топ-позиций в пик: дефицит обнуляет весь маркетинг.
